What we heard

The brief

A one-person build practice selling a productised offer to non-technical founders. The site is set as a well-built instrument: concrete and graphite, one safety-orange signal that marks action. The mark replaces the plain-text name in the header.

The site's booking key: an A on the signal face, with the graphite edge and hard offset every key on the site has.

  • The mark and the one call to action are the same object
